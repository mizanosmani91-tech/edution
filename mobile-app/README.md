# EDUTION Android অ্যাপ

এটা EDUTION এর নেটিভ Android অ্যাপের সোর্স — [Capacitor](https://capacitorjs.com) দিয়ে বানানো, যেটা মূলত একটা "স্মার্ট WebView র‍্যাপার": ওয়েব অ্যাপ (`edution.xyz`) কেই নেটিভ শেলে চালায়, তাই ফিচার যোগ/বাগ ফিক্স সব জায়গায় একই জায়গা থেকে (মূল Laravel অ্যাপ) হয় — এই ফোল্ডারে আলাদা করে কোড লেখার দরকার হয় না।

## কীভাবে কাজ করে

- **একটাই অ্যাপ, সব প্রতিষ্ঠানের জন্য** — Play Store এ "EDUTION" নামে একটা অ্যাপ থাকবে।
- প্রথমবার খোলার সময় `www/index.html` (লঞ্চার পেজ) দেখায় — ব্যবহারকারী তার প্রতিষ্ঠানের সাবডোমেইন/লিংক লেখে (যেমন `flourish`)।
- সেটা ফোনে সেভ হয়ে যায়, এরপর থেকে অ্যাপ খুললেই সরাসরি সেই প্রতিষ্ঠানের লগইন পেজ (`https://flourish.edution.xyz/`) দেখায়।
- লগইন পেজে (নেটিভ অ্যাপ থেকে খোলা হলে) "অন্য প্রতিষ্ঠানে প্রবেশ করতে চান?" লিংক থাকে — সেটায় চাপলে আবার লঞ্চার পেজে ফিরে যায়।

## প্রথমবার সেটআপ (একবারই লাগবে)

এই কাজগুলো তোমার নিজের কম্পিউটারে করতে হবে, Android Studio ইনস্টল থাকা লাগবে (ফ্রি, [developer.android.com/studio](https://developer.android.com/studio) থেকে ডাউনলোড করা যায়)।

```bash
cd mobile-app
npm install
npx cap sync android
npx cap open android
```

শেষ কমান্ডটা Android Studio খুলে দেবে, প্রজেক্ট আগে থেকেই তৈরি করা আছে (`android/` ফোল্ডারে)।

## অ্যাপ আইকন

`www/icons/` ফোল্ডারে মূল Laravel অ্যাপের PWA আইকন (`public/icons/icon-512.png`) কপি করে বসিয়ে দাও, তারপর Android Studio তে:
- রাইট-ক্লিক `app` → New → Image Asset → Icon Type: Launcher Icons → `icon-512.png` সিলেক্ট করে জেনারেট করলেই সব সাইজের আইকন অটো তৈরি হয়ে যাবে।

## সাইনড AAB বানানো ও Play Console এ আপলোড

তোমার Google Play Developer অ্যাকাউন্ট যেহেতু আছে, ধাপগুলো:

1. Android Studio তে: **Build → Generate Signed Bundle / APK** → **Android App Bundle** সিলেক্ট করো।
2. প্রথমবার হলে **Create new...** চেপে একটা নতুন keystore (সাইনিং কী) তৈরি করো — এই ফাইলটা (`.jks`) ও পাসওয়ার্ড **নিরাপদ জায়গায় ব্যাকআপ রাখো**, হারিয়ে গেলে ভবিষ্যতে অ্যাপ আপডেট দেওয়া যাবে না।
3. **release** বিল্ড ভ্যারিয়েন্ট সিলেক্ট করে Finish করলে `app-release.aab` ফাইল তৈরি হবে।
4. [Google Play Console](https://play.google.com/console) এ লগইন করো → **Create app** → নাম "EDUTION", ক্যাটাগরি "Education"।
5. **Production → Create new release** এ গিয়ে `.aab` ফাইলটা আপলোড করো।
6. Play Console এর বাধ্যতামূলক ধাপগুলো পূরণ করো: প্রাইভেসি পলিসি লিংক (মূল সাইটে একটা `/privacy` পেজ বানিয়ে সেই লিংক দেওয়া যায়), অ্যাপ কন্টেন্ট রেটিং প্রশ্নমালা, স্ক্রিনশট (ফোনে অ্যাপ চালিয়ে স্ক্রিনশট নিয়ে), Feature graphic (1024×500 px ছবি) ও অ্যাপ আইকন (512×512 px)।
7. রিভিউতে জমা দাও — সাধারণত কয়েক ঘণ্টা থেকে কয়েকদিন সময় লাগে Google এর রিভিউ শেষ হতে।

## পরবর্তীতে আপডেট দেওয়া

যেহেতু এটা মূলত ওয়েব অ্যাপের র‍্যাপার, বেশিরভাগ ফিচার/বাগ-ফিক্স আপডেট **এই অ্যাপ রিবিল্ড না করেই** লাইভ হয়ে যাবে (কারণ ভেতরের কন্টেন্ট সরাসরি `edution.xyz` থেকে লোড হয়)। শুধু এই ক্ষেত্রে নতুন করে বিল্ড/আপলোড লাগবে:
- অ্যাপের নাম/আইকন বদলালে
- `capacitor.config.json` এ কিছু বদলালে (যেমন নতুন ডোমেইন যোগ করা লাগলে `allowNavigation` এ)
- Android নিজেই নতুন পলিসি/SDK ভার্সন আপডেট চাইলে

## গুরুত্বপূর্ণ সীমাবদ্ধতা

- এই স্ক্যাফোল্ড কোড-সম্পূর্ণ ও যাচাই করা হয়েছে (`npx cap add android` চালিয়ে প্রজেক্ট সফলভাবে তৈরি হয়েছে), কিন্তু বাস্তব ডিভাইসে ইনস্টল করে/সাইন করে/Play Console এ আপলোড করে টেস্ট করা এই এনভায়রনমেন্ট থেকে সম্ভব হয়নি — Android Studio ও Play Console এক্সেস দুটোই ব্যবহারকারীর নিজের কম্পিউটারে/অ্যাকাউন্টে লাগে।
- পুশ নোটিফিকেশন এখনো যোগ করা হয়নি — চাইলে পরে `@capacitor/push-notifications` + Firebase Cloud Messaging দিয়ে যোগ করা যাবে।
