# ১ ক্লিক সিভি মেকার

একটা সম্পূর্ণ স্বতন্ত্র, স্ট্যাটিক PWA — Laravel অ্যাপ থেকে আলাদা, কোনো ব্যাকএন্ড/সার্ভার লাগে না।

## যা আলাদা করে
- **এক ক্লিকে শেয়ার**: PDF জেনারেট করে সরাসরি ফোনের নেটিভ শেয়ার শীট (WhatsApp/Email/Messenger) খুলে যায় — আলাদা করে ডাউনলোড করে অ্যাটাচ করা লাগে না।
- **কখনো রিটাইপ করা লাগে না**: সব তথ্য ব্রাউজারের localStorage-এ সেভ থাকে, অ্যাপ আবার খুললেই আগের সিভি রেডি।
- **বাংলা পেশাভিত্তিক প্রি-ফিল লাইব্রেরি**: পেশা বেছে নিলেই ক্যারিয়ার অবজেক্টিভ ও স্কিল সাজেশন অটো-ফিল হয় (`js/data.js`)।
- **সম্পূর্ণ অফলাইন-ফার্স্ট PWA**: হোমস্ক্রিনে ইনস্টল করা যায়, ইন্টারনেট ছাড়াও কাজ করে, কোনো লগইন/অ্যাকাউন্ট লাগে না।
- **প্রাইভেসি**: ডেটা কখনো কোনো সার্ভারে যায় না — শুধু ব্যবহারকারীর ডিভাইসে থাকে।

## চালানো
যেকোনো স্ট্যাটিক ফাইল সার্ভার দিয়ে চালানো যায়, যেমন:

```bash
cd cv-maker
python3 -m http.server 8080
```

তারপর ব্রাউজারে `http://localhost:8080` খুলুন। (`file://` দিয়ে সরাসরি খুললে Service Worker কাজ নাও করতে পারে — লোকাল সার্ভার দিয়ে চালানোই ভালো।)

## ফাইল স্ট্রাকচার
- `index.html` — ফর্ম + লাইভ প্রিভিউ UI
- `css/style.css` — স্টাইল ও ৩টা CV টেমপ্লেট (Modern/Classic/Minimal)
- `js/data.js` — পেশাভিত্তিক প্রি-ফিল কন্টেন্ট লাইব্রেরি
- `js/app.js` — স্টেট, localStorage, প্রিভিউ রেন্ডার, PDF জেনারেশন ও শেয়ার লজিক
- `manifest.webmanifest`, `sw.js`, `icons/` — PWA ইনস্টল ও অফলাইন সাপোর্ট
